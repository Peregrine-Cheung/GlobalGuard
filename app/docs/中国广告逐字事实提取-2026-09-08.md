# 中国广告逐字事实提取（2026-09-08）

## 目标

中国广告路径当前为 `cn-ad-facts-v2`。模型只负责把标题、商品文案和可可靠转写的图片文字拆成逐字事实；模型不输出风险等级、规则编号、法规解释、证据是否充分、修改建议或企业身份信息。最终风险仍由版本化本地规则和人工复核决定。v2在v1基础上增加数字及单位的完整、有序、不重复核对，以及引证类型必须携带逐字引证token。

## 结构

顶层只允许：

- `imageTextStatus`：`readable_text`、`unreadable_text_seen` 或 `no_text_seen`；
- `imageText`：可靠转写的图片原文，或 `NONE`；
- `claims`：最多12条逐字事实。

每条事实必须包含且只能包含：

- `id`：`claim-1` 至 `claim-12`，不可重复；
- `verbatim`：连续的逐字原文，不允许改写或概括；
- `source`：`product_title`、`product_copy` 或 `image_text`；
- `kind`：最高级/排名、数值/统计、效果、评价/背书、引证或一般商品表述等语言表面类型；
- `numericTokens`：原文中实际出现且含数字的片段；
- `referenceTokens`：原文中实际出现的报告、机构、研究、测试、统计口径或引证片段。

## 本地校验与决策边界

- `verbatim` 必须能在声明的来源原文中连续找到；模型改写或补写内容会使整次响应安全降级。
- 数值和引证 Token 必须是该条 `verbatim` 的原文子串；模型不能把 `98%` 改成 `99%`，也不能补出不存在的“权威机构”。
- 图片文字状态与转写必须一致；看见但读不清时只能返回 `NONE`，不能猜字。
- 顶层或事实项出现 `severity`、`ruleId`、`finding`、`action` 等额外决策字段时拒绝整次响应。
- 服务端剥离客户端提交的 `cnClaimFacts`、OCR 和模型 finding，只接受本次服务端模型调用通过校验的事实。
- 中国规则只对逐字原文重新执行本地固定词语和数值模式判断；`kind` 本身不会直接产生违法结论。
- 广告中写有“测试报告A”只证明素材引用了该字样，不等于后台已经提供真实报告。证据输入仍由独立的证据链接/内部编号字段控制。
- 中国路径完全忽略模型自写风险文案，防止模型绕过本地标题、来源和人工复核模板。

## 审计

通过校验的 `cnClaimFacts`、`cn-ad-facts-v2` 策略版本和 OCR 状态进入审计及输入指纹。规则风险的位置可引用命中的 `claimFactIds`，便于回到原文事实，但不代表模型判断被采纳为法律结论。

## 离线验收

- `fixtures/cn-ad-facts-v2/cases.json`：9个合成结构夹具，含2个接受和7个拒绝案例；该数据不是人工金标准或真实广告准确率样本。
- `npm test`：66/66 通过。
- `npm run evaluate`：24/24 合成规则回归通过；不外推为真实世界表现。
- `npm run check:browser`：16组隔离浏览器检查通过，`pageErrors=[]`。浏览器使用拦截的合成 live 形状响应，只验证渲染与边界，没有调用真实模型。
- 前端仅显示逐字事实、来源位置、语言表面类型、数值原文和引证原文，并明确标注“不含法律判断”。

## 尚未完成

- 没有独立人工标注，不能报告主张抽取完整率、准确率或图片 OCR 表现。
- 2026-09-09已对`cn-ad-facts-v2`执行一次非敏感合成真实调用，4条逐字事实通过schema；这不能证明稳定遵循率或抽取准确率。
- 当前本地绝对化词语和证据词只是低监管家居收纳 MVP 的有限规则集合，不是完整中国广告法知识库。
- 没有核验引用报告内容、统计口径、时间范围、样本设计或授权链；这些仍需人工打开真实证据。
