## 证据使用原则

1. 产品风险卡片只链接规则包白名单中的来源。
2. 模型输出未知来源 ID 时，后端直接丢弃该条结论。
3. 来源页面更新后必须生成新规则包版本，不覆盖历史审计结果。
4. 高风险法律适用、企业主体和安全信息保留人工复核。
5. 欧美代表规则包是当前演示深度，不是产品永久市场边界。
