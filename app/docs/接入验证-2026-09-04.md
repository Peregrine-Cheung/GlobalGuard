## 接入保护实测

- `.env.local` 被 Git 忽略；扫描 `app` 中非环境配置文件，未找到实际新密钥。
- 健康接口不返回密钥，静态路径不能读取 `.env.local` 或通过父路径访问它。
- 配置密钥但未获应用授权时，分析与复检均保持本地模式。
- 网络请求只允许明确的官方 HTTPS 端点，并拒绝重定向。
- 输出格式错误、截断、普通参数错误均不能变成“成功且无风险”。
- 只有明确的模型不可用响应允许尝试备用模型；错误不暴露供应商原始正文。

## 复检与审计改进

1. 复检重新解码输出图，取得实际画布尺寸并运行边缘颜色检查，不由修复步骤直接将边框、促销标记写成已消除。
2. 改图后促销内容状态是未知，保留原文字作为待查线索；边缘启发式不能证明存在装饰边框，也不能证明图片无风险。
3. 美国与中国图片检查由服务端添加检测覆盖复核项，客户端不能清空它。该项是系统能力边界，不是平台违规。
4. “没有硬阻断但仍需人工复核”显示为待复核，不再显示通过。
5. 图片 data URL 的 SHA-256 和完整输入指纹被写入审计；不同图片即使文件名、尺寸相同也会得到不同内容指纹。哈希针对所提交的数据表示，不是抗篡改签名或平台认证。
6. 导出包含初检、复检及两次字段快照；用户修改输入或更换图片会使旧结果失效，延迟返回的旧请求不会覆盖新输入。
7. 真实图片不再按固定比例盲目裁边；可下载 720×720 待复核草稿，扩画布不被描述为增加原图细节。
