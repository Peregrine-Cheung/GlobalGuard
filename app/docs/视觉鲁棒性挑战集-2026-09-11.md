# 视觉鲁棒性挑战集（2026-09-11）

## 当前结论

第二套视觉评测数据集`globalguard-visual-robustness-v1`已完成离线生成、一次单人人工复核和v5真实盲跑。它独立于基础六图，包含10张720×720确定性合成SVG、构造真值和空白人工盲标模板。首轮10次请求全部获得供应商响应，本地结构契约通过9次，严格单人人工一致3张，总消耗18,662 Token；v6已完成离线优化但尚未真实复测。

## 盲标入口与隔离

- 本地入口：`/annotation.html?dataset=robustness-v1`
- 页面只显示`robustness-01`至`robustness-10`的中性顺序编号和图片。
- 浏览器页面不读取`construction-truth.json`、挑战名称或模型输出。
- 基础六图与鲁棒性十图使用不同的`datasetId`和`localStorage`键，不会混用草稿。
- 导出前必须通过同一套OCR状态、逐字文本、区域坐标和可见事实绑定校验。

## 首轮调用控制与实际消耗

`npm run preview:robustness-live`只生成本地预览，不访问供应商。v5首轮实际执行遵守：

- 最多10次供应商请求，每张图最多一次；
- 禁止自动重试，禁止模型回退；
- 人工盲标完成且结构校验通过前不执行模型；
- 原预算范围15,000–25,000 Token，硬上限25,000 Token；
- 实际10次供应商响应共18,662 Token，没有触发预算保护。

估算不是计费承诺。实际供应商Token可能随图像复杂度和服务端计量变化。

## 验证结果

- `npm run check:robustness-fixtures`：12个生成产物全部匹配，无漂移；
- `npm test`：103/103通过；
- `npm run check:browser`：22组通过，`pageErrors=[]`，验证中心已展示十图首轮证据；
- 1440px桌面和390px手机长图人工复核未发现重叠、截断、乱码或横向溢出；
- 浏览器检查本身使用占位凭据并阻断供应商请求，额外真实调用0次；上文10次属于独立、已授权的v5首轮盲跑。

## 结果边界

构造真值只说明图片如何被确定性生成，不是人工金标准。后续单人标签只能称为单人人工复核；即使模型与其一致，也不能直接写成模型准确率、真实商家图片表现、法律正确率或平台通过率。
