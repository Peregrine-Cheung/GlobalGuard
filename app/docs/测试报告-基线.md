## 已执行验证

### 1. 语法与自动测试

执行命令：

```powershell
node --check server.mjs
node --check src/rule-engine.mjs
node --check src/model-router.mjs
node --check public/app.js
npm test
```

实测结果：9 项测试全部通过，0 失败。

覆盖内容：

- Google 当前最低尺寸与 2027 未来尺寸要求分层；
- 720×720 清洁图片通过；
- 中国绝对化表达与数据依据分别识别；
- “第一次”“第一季度”等普通序数语境不按排名主张处理；
- 非欧盟制造商缺失欧盟责任人信息时阻断；
- 欧盟在线要约信息完整时通过；
- 模型返回的未知来源 ID 被丢弃。
- 本地密钥配置只读取允许字段，且不会覆盖进程中已有配置。

### 2. 合成回归集

执行命令：

```powershell
npm run evaluate
```

数据集：`globalguard-synthetic-regression-v1`，共 24 例。

实测结果：

- 规则集合精确匹配：24/24；
- 状态精确匹配：24/24；
- 回归集 precision：1.0000；
- 回归集 recall：1.0000；
- 本次规则计算耗时：3.356 ms。

上述 precision/recall 仅表示预设回归案例与预期规则标签的一致性，**不代表真实商品素材上的模型准确率或法律判断准确率**。

### 3. 本地服务与接口

已验证：

- `GET /` 返回 200；
- `GET /api/health` 返回服务、规则包和 ModelRouter 配置状态；
- `POST /api/analyze` 可完成三条市场路由；
- `POST /api/recheck` 生成新的分析 ID 和输入指纹；
- ModelRouter 未配置时明确显示 `local-rules`，没有伪造真实模型调用。

补充限制（2026-09-04）：不同指纹只能证明输入不同、服务重新运算，不能证明输出图片经独立视觉检测。本表使用合成输入及信号字段，不应作为实际商品图像已合规的证据。
