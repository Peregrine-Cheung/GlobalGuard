# GlobalGuard 技术架构

## 设计目标

复赛版优先证明一条稳定、可解释、可复检的黄金链路，而不是构建大而全的法规数据库。系统把确定性事实、模型观察和人工判断明确分层。

## 请求链路

```text
浏览器工作台
  ├─ 商品图片、文案、市场、品类和页面字段
  ├─ 浏览器图片尺寸与边缘信号
  └─ 修复前后像素结果
          │
          ▼
Node API 服务
  ├─ Route：选择 US_GOOGLE / CN_ADS / EU_GPSR
  ├─ Detect：执行版本化确定性规则
  ├─ 赛事 Token Plan（可选，须先取得应用使用授权）
  │    ├─ qwen3.7-plus：OCR + 视觉观察 + JSON 辅助输出
  │    └─ qwen3.6-plus：仅在主模型明确不可用时回退
  ├─ Explain：绑定来源、适用范围和检索日期
  ├─ Fix：先生成保护/候选移除区域与裁剪影响计划，再执行可验证的最小修复或生成待确认清单
  └─ Recheck：使用相同版本规则重新分析修复结果
          │
          ▼
审计输出
  ├─ 输入指纹
  ├─ 分析 ID / 复检 ID
  ├─ 规则包版本
  ├─ 模型状态与调用阶段
  ├─ 浏览器本地修复确认与区域保护计划
  └─ 风险、依据、动作和人工复核标记
```

## 可信度控制

1. **规则优先**：尺寸、字段完整性和固定词语匹配由确定性代码处理。
2. **模型限权**：多模态模型被要求描述可见事实，并选择规则包白名单中的来源 ID。
3. **来源校验**：未知来源的模型结论会被丢弃。白名单不是引用内容正确性的证明，仍待补充规则正文约束与人工评测。
4. **时间分层**：2027 尺寸要求标记为准备度风险，不冒充 2026 年当前驳回项。
5. **信息不生成**：欧盟责任人、企业地址和安全信息必须由真实档案提供。
6. **人工出口**：广告语境、引用数据、生成内容标识和高风险法律适用均保留人工确认。
7. **安全降级**：Token Plan 缺少密钥、缺少应用使用授权或调用失败时，明确显示本地规则结果，不伪造 AI 成功状态。
8. **密钥保护**：请求限制为明确批准的官方 HTTPS 端点，拒绝重定向；错误不回传供应商原始响应体。
9. **响应校验**：结构不正确或被截断的结果不得当作无风险结论；一般参数错误不触发付费回退。
10. **中国逐字事实**：`cn-ad-facts-v2` 只接收能回到标题、文案或图片 OCR 原文的主张；阿拉伯数字及紧邻单位必须完整、有序且不重复，引证类型必须保留逐字引证token；语言类型不能直接成为法律结论。
11. **欧盟字段事实**：`eu-offer-facts-v2` 按固定顺序回显用户已填写字段并定位用户所给档案中的最短连续原文；缺失字段必须为`null`，引用不超过240字符且必须绑定来源编号，字段完整性和风险仍由本地规则决定。
12. **真实调用预算保护**：欧盟 schema 冒烟默认只预览；执行必须双参数确认，并关闭模型回退和自动重试，供应商请求上限为1次。

## 验证边界（2026-09-04）

原图及修复草稿已分别通过真实后端请求得到视觉结果，能识别文字和残留徽章；期间一次结构错误安全降级。尚未完成真实商家样本质量评测。浏览器会重新解码修复图并提取尺寸和边缘信号；不会用修复动作直接将视觉风险标为已消除。服务端仍保留图片语义与主体完整性人工复核项。图像输入 SHA-256、完整输入指纹及初检/复检字段快照被记录，但不是签名或外部认证。模型观察、请求ID和Token用量随结果返回；v3 已加入经过本地结构校验的文字区域证据框。修复前保护门把商品/场景/归属不明及未绑定风险的文字区域设为保护区，若其越出拟保留裁剪矩形即硬阻断；与促销风险绑定的 overlay 区域只作为候选移除，并需显式确认。硬阻断后可以选择 `safe-reframe-no-crop`，其裁剪矩形固定为完整源图，所有观察区域均转为保护区；复检使用 `source-content-preserved` 语义状态，保留原有促销文字和边框信号。该机制只保护已检测区域且依赖本地操作者复核，尚未证明真实模型区域准确率，也不是完整商品分割或清除验收。

2026-09-04 已基于用户提供的赛事方明确回复启用本队专用授权，详见 [授权记录](赛事模型使用授权-2026-09-04.md)。普通 Token Plan 通用使用范围没有因此变化。当前服务拒绝跨站POST、非JSON和外部图片URL；最多一个并发模型请求、每分钟六次应用调用。这不是完整的公网安全方案。

## 当前存储策略

### 美国主图事实约束升级（2026-09-04）

`src/us-visual-facts.mjs` 的当前离线协议 `us-visual-facts-v7` 限定模型只返回可见事实类别、描述、文字归属、三态 OCR 和最多8个归一化文字区域，本地模板生成风险标题、解释、建议和来源。v7在v6实测基础上增加确定性硬边界：`decorative_border`、`occluded_product`、`multiple_products`和`low_clarity`等非文字事实必须使用`textOrigin=not_applicable`且`regionId=null`；明显分离的促销文字逐区报告；商品轮廓外独立吊牌按场景文字处理。v7只完成离线测试，尚无真实模型语义结果；最近真实证据仍是v6六张复测。详见 [视觉鲁棒性十图实测与v6优化](视觉鲁棒性十图实测与v6优化-2026-09-11.md) 和 [美国视觉v7离线协议](美国视觉v7离线协议-2026-09-11.md)。

### 中国广告逐字事实升级（2026-09-08）

`src/cn-ad-facts.mjs` 的 `cn-ad-facts-v2` 只允许模型输出图片文字状态、可靠转写和最多12条逐字广告事实。每条事实的原文必须能在声明的标题、商品文案或图片 OCR 中连续找到；本地程序重新抽取其中所有阿拉伯数字及紧邻单位，与模型`numericTokens`逐项核对，拒绝遗漏、重复、乱序或捏造；引证类型不得缺少逐字引证token。模型不能输出规则编号、严重度、法律解释或动作。服务端剥离客户端自报的 `cnClaimFacts`；规则引擎忽略中国路径的模型 finding，只把通过校验的逐字事实用于本地固定规则回溯和审计。v2已完成一次非敏感合成文本真实结构调用，没有独立准确率证据；详见 [模型契约优化与复测](三市场模型契约优化与复测-2026-09-09.md)。

### 欧盟在线要约字段事实升级（2026-09-08）

`src/eu-offer-facts.mjs` 的 `eu-offer-facts-v2` 固定按顺序核对9个在线要约字段。模型只能逐字回显页面已有值，并可从用户给出的档案摘录中返回包含该值的最短连续引用；空字段必须返回 `null`，引用最多240字符且没有来源编号时不得返回。模型输出的来源编号、规则、严重度、法律解释和动作都会被拒绝。服务端剥离客户端自报的 `euFieldFacts`，欧盟路径不接收模型 finding。通过校验的字段事实可供本地缺失规则关联和审计，档案全文仅以来源编号、长度和 SHA-256 摘要进入服务端审计，浏览器导出不嵌入原文。v2已完成一次非敏感合成字段真实结构调用，没有来源真实性验证或独立准确率证据；详见 [模型契约优化与复测](三市场模型契约优化与复测-2026-09-09.md)。

2026年9月9日新增受控冒烟入口：固定非敏感合成字段和档案摘录，默认只生成即将发送内容的预览；实际执行必须显式双确认，且禁用模型回退和重试。仅成功通过本地 schema 的原始结构、规范化结果、请求ID和Token用量可落盘；供应商原始错误正文与密钥不保存。本轮只完成预览，没有真实请求或Token消耗。

### 三市场统一事实契约门禁（2026-09-09）

`src/model-contract-evaluator.mjs` 统一调度三条独立校验器，但不把三市场 schema 合并为一个模糊格式。`fixtures/model-contracts-v1/manifest.json` 固定当前策略版本、夹具入口、模型允许返回的事实和本地决策归属；策略版本漂移会直接使评测失败。当前每条路径包含2个接受和4个拒绝合成案例，共18例。`scripts/evaluate-model-contracts.mjs --check` 将运行结果与确定性证据文件比较，`scripts/verify-demo.mjs` 再串联自动测试、规则回归、模型契约和视觉夹具四道离线门禁。美国 v3 同步增加顶层字段严格白名单，模型自写的严重度或其它额外字段不再被静默忽略。详见 [三市场模型事实契约与演示验收](三市场模型事实契约与演示验收-2026-09-09.md)。

### 本地验证中心（2026-09-09）

`/validation.html`通过只读`GET /api/validation-center`获取当前规则包、三市场观察策略、静态确定性报告及其SHA-256。接口会重新运行当前契约评测，并比较静态报告与计算结果；页面只有在报告同步、27个案例全部通过、三条策略版本一致时显示绿色一致状态。接口不返回密钥、环境变量或供应商正文，也不发起真实模型调用。页面同时固定展示模型准确率、法律正确率、平台审核和真实企业试用等未测量项，避免把结构门禁误读为合规证明。详见 [本地验证中心](本地验证中心-2026-09-09.md)。

复赛演示版不持久化用户上传图片和密钥。审计记录由浏览器显式导出。后续若需要企业试点，再加入最小化、可删除、有权限控制的数据存储。

## 范围边界

当前规则包只用于家居收纳低监管品类演示。美国 Google 路径已有像素修复与规则复检原型，独立视觉闭环仍待验收；中国路径强调语境与证据；欧盟路径强调页面级信息义务。高监管品类和更多平台属于后续扩展，不在当前规则包覆盖范围内。
